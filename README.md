# 🐷 Pig365 – Dual-Root Domain (IDN/ASCII) Architecture

> Open-source modular web ecosystem and dual-root DNS architecture built independently by a Taiwanese elementary school student developer.

---

Hello all seniors, engineers, and partners!

I want to share the recent independent design, development, and deployment project: **Pig365**.

To understand real-world Internet infrastructure and DNS operation principles through hands-on practice, we experimented with Cloudflare to establish a **"Dual-Root Domain DNS (IDN & ASCII) System"**.

---

### 🌐 Network Architecture & Domain Configuration

* **ASCII Main Domain**: `pig365.xyz` / `pig365.pro` / `pig365.vip` — Main ASCII application and component service domains.
* **IDN Publishing Domain**: `豬豬集團.xyz` / `豬豬集團.pro` / `豬豬集團.vip` (`xn--ndsx45ja417h.xyz`) — Chinese IDN publishing and content display domain (e.g., `Publishing.豬豬集團.xyz`).

---

### 🛠️ Project Modules & Technical Highlights

* **Modular Component Ecosystem**: Features frontend modules including:
  * `SS` (Lightweight Static Service, e.g., Pig SS Meet: [Live Sandbox Demo](https://3000-idfj1lbwdo4g4r1icxx1s-02b9cc79.sandbox.novita.ai/ww))
  * `WW` (Web Display Module)
  * `Ue` (User Experience & Interaction Module)
* **DNS-Level IDN & Punycode Translation**: Enables native resolution and functionality for Chinese domain names on the open Internet.
* **Canonical 301 Redirects & Brand Alignment**: Standardizes primary URLs while smoothly redirecting traffic from the publishing domains to the main service.
* **Cloudflare Edge Routing & SSL**: Multi-domain edge routing and edge TLS/SSL certificate issuance with zero backend server maintenance overhead.
